# Corrections: Weekly client report

Newest first. These override everything else.

## 2026-09-25 · after run 4

Name the channel (paid search, paid social, email) next to every number. Clients get confused by blended totals.

- Was: Conversions were up 9% this week.
- Should be: Paid search conversions were up 9% (214 vs 196), paid social was flat.

## 2026-09-11 · after run 3

End every report with exactly one ask for the client, with a date. Not two, not a general "let us know".

- Was: Let us know if you have any thoughts on the plan.
- Should be: Could you confirm the revised budget by Wednesday 16 September?

## 2026-08-28 · after run 2

Never use exclamation marks, and never write "unfortunately". State what happened instead.

- Was: Unfortunately the email campaign underperformed!
- Should be: The email campaign opened at 18% against a target of 24%.
