# Metrics

The numbers you are measured on or watch, with the target and where to find them. One per line, like this: `- **Reports sent on time** (metric) — target: every Friday by 15:00.`

- **Reports sent on time** (metric) — target: every Friday by 15:00; the tracker is in Notion.
- **Answer time for tier-one clients** (metric) — target: within four working hours (the agency handbook).
