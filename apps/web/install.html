Loam

Connect Loam to your AI agent

Loam works with any AI agent that can run a local MCP server. You only do this once, and it takes a few minutes. You need a folder you already set up in the Loam app.

Claude Desktop Claude Code, Cursor, Codex, VS Code, Gemini CLI, Windsurf, others

Claude Desktop

The easiest way: one file, nothing else to install. You need Claude Desktop on a Mac or Windows computer.

  1. 1. Download the extension

    It is one small file called loam.mcpb. It is the part that lets Claude read your folder.

    Download loam.mcpb

  2. 2. Open it with Claude Desktop

    Double-click the file, or open Claude Desktop, go to Settings, then Extensions, and drag the loam.mcpb file into that window. When Claude asks whether to install it, choose Install.

  3. 3. Choose your folder

    Claude asks which folder Loam may use. Choose the folder you set up in the Loam app: the one that has a file called AGENTS.md inside. Then turn the extension on.

Claude Code, Cursor, Codex, VS Code, Gemini CLI, Windsurf and others

These agents start Loam with one command. You need Node version 22 or newer: run node --version in a terminal to check. The first start downloads the Loam server (about 15 MB) and can take up to a minute.

Open yours:

{{installAgents}}

Any other agent that can run a local (stdio) MCP server works the same way. A chat in a web browser (ChatGPT, Gemini or claude.ai) cannot run a local server, so it cannot save to Loam. You can still give it a process or a skill: open it in the Loam app and press Copy for any chat, then paste the text into the chat. Any agent that opens your folder can also read it by following AGENTS.md.

Check that it works

Start a new chat in your agent and type:

Run my Loam onboarding interview

Your agent should start asking about your role and your day. If it doesn’t, check that Loam is switched on in the agent’s MCP settings and that the folder is the right one. Terminal users can run npx -y {{npmPackage}} --check --folder <your folder>, which says what is wrong in plain words.

What it can and can’t do

It only reads and writes inside the folder you chose. It makes no network requests, and the code is open on GitHub. Your agent only changes your files when you ask it to, and it shows you what changed.
