How it works

  1. 1. Answer an interview

    Your own AI agent asks four short questions about your work, one at a time. It takes about four minutes.

  2. 2. See what to automate

    Your recurring work is mapped, with the hours it takes per year and what is worth handing over first.

  3. 3. Get files you own

    Everything lands in a folder on your disk, with your examples and corrections kept next to each process.

  4. 4. Connect your agent

    One click for Claude Desktop; for Cursor, Codex, VS Code or Gemini, send your agent one message and it sets Loam up for you. Then ask for your weekly report in a single sentence.

What you get

  • A folder that is yours

    Plain files on your computer. Read them, back them up, move them. No account, no lock-in.

  • Works with the agent you already use

    Claude, Cursor, Codex, VS Code (Copilot), Gemini CLI, Windsurf and any agent that can run a local MCP server. Your skills are copied where each of them looks. See the setup for each. Private by design, safe by default

Your data never leaves your computer. There is no server, no account and no sign-up: the app is a web page that reads and writes the folder you choose, and nothing else. The code is open, so you can check that.

Skills from other people are checked before they are added. Anything that deletes files, uses the internet, sends your data out, asks for passwords or tries to change how your AI behaves is refused, with no way to override it. Imported instructions can never write to your folder and can never reach the network.
